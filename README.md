# CareFirst Home Nursing Website

Website for CareFirst Healthcare Services (Pvt) Limited (Karachi, Lahore and Islamabad / Rawalpindi).

## Pages
- `index.html`: Home
- `services.html`: Services and nursing procedures
- `equipment.html`: Medical Equipment
- `why-us.html`: Why Us
- `blog.html`: Blog with health tips articles
- `hiring.html`: We're Hiring, with job application form
- `appointment.html`: Book Appointment form
- `contact.html`: Contact Us, with message form

Contact and appointment forms open thank-you pages. The job application form sends details to CareFirst on WhatsApp (+92 333 3045046).

## Folders
- `css/style.css`: all styles and animations
- `js/script.js`: menu, scroll effects and forms
- `images/`: logo and photos

## Publish on GitHub Pages
Upload everything in this folder to the repository (keep the folders), then
Settings > Pages > Branch: main, / (root) > Save.
